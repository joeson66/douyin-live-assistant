# 抖音直播助手

用于抖音生活服务本地直播专业版中控台的开源浏览器助手。支持商品轮换讲解、网页原生快捷回复、仅本账号已发送预设评论的随机置顶、货架同步、异常恢复和运行记录。MIT 许可，非平台官方工具。

**此公开版不包含优惠券读取、配置、发放、停止或循环功能。** 默认商品和话术列表为空，用户须从自己的页面读取并选择。没有内置商家、账号、商品ID或活动话术，没有后台服务器及统计分析。

## 安装：任选一种

### Chrome 独立扩展

1. 下载仓库 ZIP 并解压。
2. 打开 `chrome://extensions/`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中本项目的 `chrome-extension` 文件夹。
4. 打开或刷新 [直播中控台](https://eos.douyin.com/livesite/live/current)。

### 用户脚本

1. 安装支持用户脚本的管理扩展，例如篡改猴。
2. 将本项目的 `douyin-live-auto.user.js` 导入管理扩展。
3. 打开或刷新直播中控台。

两种方式只启用一种。拉取源码本身不会自动运行；独立扩展方式不需要篡改猴。公开版使用独立配置键，不自动迁移旧商家专用版本的商品、话术和日志；更新前停止并禁用旧助手，然后重新配置。

## 使用

1. 点击“刷新商品列表”，勾选需要轮换的商品，设置顺序与讲解间隔。
2. 点击“读取网页快捷回复”，从网页已有话术中勾选，设置发送间隔。读取本身不会发送。
3. 如需随机置顶，勾选置顶并设置间隔；只会选择本账号发送且与所选话术全文一致的评论。
4. 保存设置，再手动“开始”。“停止”取消后续任务，刷新后不会自动启动。

商品按实时货架读取，不按价格猜商品。发现缺失、歧义、未知提交结果或人工草稿时，相关操作会等待或暂停；日志显示原因。异常恢复会逐步增加等待，不补发结果不明的旧操作，手动停止后不会自行重启。

## 支持范围

只在 `https://eos.douyin.com/livesite/live/current*` 注入；不适用于抖音所有后台，也不是小红书助手。浏览器须提供 Web Locks。页面结构变更可能使商品/评论/置顶识别失效。

请保持页面、网络和浏览器运行；电脑睡眠、标签页挂起或浏览器关闭期间脚本不能执行。仓库中的桌面扩展不能直接装到 iPad Safari。

## 开发与验证

需要 Node.js 20+ 和 Python 3，无第三方构建依赖。

```sh
python3 build-extension.py
npm test
npm run test:extension
npm run check
```

`douyin-live-auto.user.js` 是唯一运行源码；`chrome-extension/content.js` 由构建脚本生成。修改源码后先重新构建，再测试。测试使用模拟页面、虚拟时钟、虚拟账号和合成商品ID，不会访问真实账号或发送评论。通过测试不等于通过所有平台页面和长时间运行验收。

公开版脱敏内容包括：通用命名空间和存储键、空默认配置、合成测试商品ID，以及排除旧脚本、截图、录制、个人路径和原商家运营数据。原始私人项目和历史版本不在公开仓库中。
